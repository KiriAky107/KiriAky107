## 你好，我是 Kronecker

计算机科学与技术专业在读。学习马列毛理论，关注现实社会与劳动者处境；写代码，也做钢琴改编、写旧体诗词。喜欢从具体的问题出发，让认识回到实践，让想法成为作品。
