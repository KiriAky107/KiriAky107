# Technology icons

The path-only SVG data in `technology.json` comes from [Simple Icons](https://github.com/simple-icons/simple-icons), version **16.36.0**, pinned to commit [`90646e4bf7f3b89df6c37e65baf3e7bc759a517c`](https://github.com/simple-icons/simple-icons/tree/90646e4bf7f3b89df6c37e65baf3e7bc759a517c).

Simple Icons is distributed under [CC0 1.0 Universal](https://github.com/simple-icons/simple-icons/blob/90646e4bf7f3b89df6c37e65baf3e7bc759a517c/LICENSE.md). Each icon entry records its exact upstream SVG URL and license identifier. The original 24 × 24 view box and path data are retained; the profile renderer supplies the display size and theme color.

Included icons: C++, Python, Rust, TypeScript, Tauri, Vue.js, Vite, Pinia, FastAPI, Pydantic, SQLite, PostgreSQL, Model Context Protocol, Ollama, Git, Linux, Docker, and GitHub Actions.

Only SVG path data is stored: no scripts, external resources, embedded styles, or remote requests are needed to render the icons. Generic concepts such as Agent, RAG, Skill, Plugin, FTS5, and sqlite-vec use the profile renderer’s own interface symbols rather than branded logos.
